# Estado de la API

No hay una API implementada ni conectada. El frontend utiliza almacenamiento del navegador y simulaciones locales. No se han añadido llamadas de red ni dependencias de servidor al reorganizarlo.

`services/api/app/api/v1`, `core`, `modules`, `schemas` y `repositories` quedan reservados según el árbol solicitado. `main.py` contiene solo comentarios para señalar su condición de reserva.
